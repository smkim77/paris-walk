# 파리 산책하기

그저 파리를 느긋하게 산책하고 싶을 뿐인데, 거리는 그냥 걷게 두질 않습니다.
개똥과 오줌 웅덩이, 머리 위 비둘기, 횡단보도의 차와 자전거, 카페 테라스와 살수차까지,
어쩔 수 없이 피해 가며 걸어야 하는 브라우저 게임입니다.
에펠탑에서 사크레쾨르까지 파리 명소를 지나며 최대한 멀리, 높은 점수를 노려 보세요.

## 조작

- ← → / A D: 좌우 이동
- ↑ ↓ / W S: 걷는 속도 (빠를수록 점수 배율이 높아요)
- Space: 점프 (똥·오줌을 뛰어넘기, 착지하면 바로 다시 점프 가능)
- P: 일시 정지
- 휴대폰: 화면 아래 ◀ ▶ 버튼(또는 좌우 드래그)으로 이동, 위아래 드래그로 속도, 점프 버튼(또는 탭)으로 점프, II 버튼으로 정지

## 파일

- `index.html`: 게임 원본 (claude.ai 아티팩트용 페이지 조각)
- `docs/index.html`: GitHub Pages에서 실제로 서비스되는 완성 페이지
- `build.sh`: `index.html`을 감싸서 `docs/index.html`을 만드는 스크립트

`index.html`을 고친 뒤에는 `sh build.sh`를 실행하고 `docs/index.html`도 함께 커밋하세요.
